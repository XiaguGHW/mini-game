# Mini-game development rules

- Work only in this repository.
- After each requested code change: inspect the diff, commit with a clear message, and push it.
- Do not run tests, lint, Gradle, Android builds, emulator runs, or APK packaging unless I explicitly ask.
- Never create or modify files under .github/workflows unless I explicitly ask.
- Never display, commit, or copy private keys, .env files, tokens, keystores, or credentials.
- Do not commit generated APKs, build folders, or other large generated files unless explicitly requested.
