# 🍓 水果生存射击 v0.1

一个可直接在浏览器运行的 2D 可爱水果生存射击小游戏。

## 🎮 游戏玩法

- **移动**：WASD 或方向键
- **攻击**：自动锁定最近敌人并持续发射种子子弹
- **升级**：击败敌人获得经验，经验满 100 升级，提升攻击力与子弹大小
- **生存**：被敌人碰到扣血，血量归零游戏结束

## 🍎 可选角色

| 角色 | 特色 | 子弹 |
|------|------|------|
| 🍓 **草莓** | 平衡型 | 小黄种子 |
| 🍇 **葡萄** | 射速快 | 葡萄籽 |
| 🍉 **西瓜** | 伤害高 | 黑西瓜籽 |

## 🍩 敌人类型

甜甜圈、马卡龙、曲奇、冰淇淋、杯子蛋糕——每种都有不同血量、速度、分值

## 🚀 如何运行

**直接双击打开 `index.html`** 即可在浏览器中游玩，无需安装任何依赖、无需构建、无需服务器。

也可用任意静态服务器（可选）：
```bash
# Python 3
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎨 技术栈

- 纯 HTML + CSS + JavaScript (Canvas API)
- 无外部素材、框架、图片生成
- 所有图形均由 Canvas 代码实时绘制
